# AI臭の禁止リスト

書いた記事を自分で点検するときに使うリストです。
髙橋の判断で、今後も足したり外したりします。

## いちばん大事なこと

AI臭の正体は、言葉づかいより**視点**です。
「セオリーや理論からみた視点がAI臭につながっている」（髙橋）

言葉を入れ替えても、評論家の席から書いていればAIくさいままです。
先にAを点検し、そのあとでB・Cを点検します。

## A. 視点のAI臭（見つけたら書き直す）

| 症状 | 例 |
|---|---|
| 結果を知った顔で、成功の理由を言い切る | 「〜したことで、ブランドは再び選ばれるようになった」 |
| セオリーを気の利いた言い回しに言い換える | 「本当に売っている価値が浮かび上がる」「記憶の中に棚を取りにいく」 |
| 現場ではありえない言い方をする | 「商品を映したくなったら」 |
| 発想を効率のいい手順として教える | 「一度〜の案を考えてみる」 |
| 読者に指導する、呼びかける | 「〜してみよう」「マネできる」「ここを盗め」 |
| 難しさを確かめずに持ち上げる | 「大胆な」「挑戦的な」「革新的な」 |
| 誰も言っていない感動を押しつける | 「胸を打つ」「誰もが涙する」 |
| 記事の外側の説明をする | 「本文には書かれていません」「記事からは不明です」 |
| 解釈に毎回ことわりを入れる | 「私の読みでは」「と読める」の連発 |

## B. 言い回しのAI臭

**使わない言葉**
見事に／絶妙な／巧みに／秀逸／圧巻／唯一無二／〜と言えるでしょう

**条件つきで使ってよい言葉**

| 言葉 | 条件 |
|---|---|
| 〜ではないでしょうか | 理由を書いたあとの提案として、1記事に1回まで（髙橋本人も使う） |
| まさに | 「ぴったり一致する」という本来の意味のときだけ。ほめ言葉の飾りには使わない（髙橋本人も使う） |
| 〜とされています | 誰が言っているのかを同じ文に書けるときだけ |
| 刺さる／エモい／世界観／インサイト／バズる／ストーリーテリング／寄り添う／共感を呼ぶ | 合わせて1記事に2回まで。「多くの広告はこれらの言葉を強く意識している」（髙橋）ので、解説がくり返しても何も言ったことにならない |

## C. リズムと構成のAI臭

- 3つ並べる（「A、B、そしてC」）。並べるなら2つか4つにするか、文章で書く
- すべての記事が同じ書き出し、同じ締め方
- すべての見出しが同じ形（今の「〜は、なぜ〜のか。」は全記事共通になっている）
- 最後を教訓や名言ふうの一文でまとめる
- 体言止めの連続
- 「——」や「：」で文をつなぐ
- 「AではなくBです」の対比を何度も使う（1記事1回まで）
- 自問自答を何度も使う（1記事2回まで）

## D. 事実のAI臭

- 出典にない数字、スタッフ名、受賞歴
- 髙橋の体験談の創作
- 制作の裏側を、見てきたように書く（想像なら「〜だったのだろうと思います」と書く）

## 点検のしかた

1. 記事を読み、Aの症状がないかを見る。あれば、その段落を作り手の席から書き直す。
2. B・Cを見て、言い回しとリズムを直す。
3. Dを見て、出典と照らす。
4. 最後に自問する。「これは20年現場にいた人が書いた文に見えるか。教科書を読んだ人が書いた文に見えないか」
