記事を書き換えるための「GitHubの鍵（トークン）」を、この端末にだけ保存します。サイトには載らないので、ほかの人は使えません。

  1. GitHub の右上のアイコン →「Settings」
  2. 左メニューのいちばん下「Developer settings」→「Personal access tokens」→「Fine-grained tokens」
  3. 「Generate new token」を押し、Token name に kaibooom-admin、Expiration は 1年 くらい
  4. Repository access で「Only select repositories」→ kaibooom を選ぶ
  5. Permissions の「Contents」を Read and write にする
  6. いちばん下の「Generate token」→ 表示された github_pat_ で始まる文字をコピー
